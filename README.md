# CPP00

42 School C++ Module 00 — basic classes, namespaces, and class-based exception handling.

## Concepts covered
- Basic class design, member functions, and constructors/destructors
- Namespaces and static members
- A Phonebook/Contact class and a class-based Account exception demo

## Exercises
ex00 ex01 ex02 

## Build & run
Each exercise has its own Makefile:
```sh
cd exXX
make
./<binary_name>
```
